# ABBA GLOBAL EXPORT AND IMPORT

Official website for **ABBA GLOBAL EXPORT AND IMPORT**, a Nigerian agricultural export business based in Wudil City, Kano State, Nigeria.

## Business Profile
- **Business Name:** ABBA GLOBAL EXPORT AND IMPORT
- **Location:** Wudil City, Kano State, Nigeria
- **Phone / WhatsApp:** +234 703 773 7995
- **Email:** abbaglobalexport@gmail.com
- **Website Purpose:** Connecting buyers with agricultural commodities from Nigeria for local and international markets.

## Key Agricultural Products
1. **Dried Hibiscus Flowers (Zobo Calyces)** (*Hibiscus sabdariffa*)
2. **Soybeans** (*Glycine max*)
3. **Groundnuts / Peanuts** (*Arachis hypogaea*)
4. **Zobo Drink** (Hibiscus infusion base)
5. **Other Agricultural Commodities** (Sesame seeds, ginger, sorghum, millet)
